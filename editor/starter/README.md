# Pelican starter

Compare per-request aligned I/O with coalesced unaligned reads for a sorted trace.

Open the extracted folder in VS Code. With Blyx 0.2.1 and its host toolchain installed, choose **Terminal → Run Task → Run Pelican** or run the following command in this directory.

```sh
blyxc native-run main.blyx
```

Expected output

```text
24
2
10
1
```

The vendor directory contains the framework source for 0.1.0 and its license texts. [Read the API guide](https://www.blyx-lang.space/packages/pelican) · [View the release](https://github.com/Rahulchaube1/blyx-pelican/releases/tag/v0.1.0)
